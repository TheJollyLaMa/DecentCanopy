  provenance boundaries and existing ecosystem Supporter discovery.

## Known limitations and deferred work

This is not a finished generic funding platform or ArtFi integration. The
[readiness audit](Supporter-Release.md) records all open issues, PR #58,
remote/preserved work and explicit next-version dispositions. Chain snapshots
can be partial/stale. Public repository linking is not identity verification.
Support is optional and is not ownership, yield or a financial-return promise.
